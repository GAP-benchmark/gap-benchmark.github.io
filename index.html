THE GENERAL AGI PROBLEM

Why existing benchmarks failed to measure real AGI.

Traditional LLM evaluations (MMLU, GSM8K, HumanEval) suffered from massive training-set contamination, test-set memorization, and narrow task alignment. When a model scores 95% on MMLU, it often memorized academic test banks rather than acquiring generalized problem-solving skills.

GAP was designed to test true out-of-distribution reasoning, autonomous multi-step agency, and cost-sustainable inference.

01

Novel Out-of-Distribution Generalization

Tasks generated with dynamic procedural parameters that cannot be scraped or memorized from internet pre-training corpora. The model must synthesize novel logical solutions on the fly, testing pure cognitive adaptability.

02

Autonomous Multi-Step Execution (TPTask)

Rather than single-turn question answering, GAP measures how models maintain coherent planning state over extended chains of thought, tool calls, and error recovery iterations (TPTask).

03

Economic Compute Reality (CPTask)

An AI system that achieves 90% accuracy but costs $50 per single reasoning step is economically impractical. GAP quantifies the exact monetary and compute cost per completed task (CPTask) to expose true commercial viability.

04

Zero-Bias Open Verification

All evaluation scripts, input seeds, and scoring rubrics are completely transparent. GAP does not accept vendor sponsorships or proprietary compute credits, preserving uncompromising scientific impartiality.

FREQUENTLY ASKED QUESTIONS

Understanding the Benchmark

Answers to common questions about evaluation methodology, metric calculations, and data freshness.

What is GAP and what does it stand for?

GAP stands for General AGI Problem. As AI laboratories frequently announce new models claiming to have achieved or approached Artificial General Intelligence (AGI), GAP provides an empirical, independent testbed to evaluate these assertions against strict criteria of cognitive versatility, zero-shot adaptation, and multi-step reasoning.

What do the TPTask and CPTask metrics represent?

TPTask (Throughput per Task / Time per Task): Measures the execution speed and inference latency required by a model to synthesize a complete solution across evaluation scenarios.

CPTask (Cost per Task / Compute Index): Measures the inference cost in US Dollars (or compute normalized index) expended to execute each standardized evaluation task.

Why does the leaderboard only display the top 10 models?

To maintain extreme signal-to-noise ratio and prevent leaderboard bloat, GAP enforces a strict policy of displaying only the top 10 ranked frontier models based on composite GAP Score. Every single entry represents a verified model tested against the exact same test harness.

How does GAP handle missing values or incomplete model metadata?

The benchmark data ingestion engine is built to be resilient: if an evaluation run has no recorded author, missing TPTask, or missing CPTask, the system gracefully handles the null fields without crashing or distorting comparative charts, ensuring scientific reliability.

Where can researchers download the raw evaluation data?

The raw evaluation dataset is continuously updated and publicly accessible in plain CSV format at https://leaderboard-5kj.pages.dev/data.csv and mirrored on our official Hugging Face organization at huggingface.co/GAP-benchmark.
